## Important boundaries

These are explanatory / promotional visuals, not authenticated UI screenshots, measured route outputs, mission-approved telemetry or NASA-endorsed artwork. In the first visual, a ChatGPT-generated artistic Mars landscape is used as a backdrop, and it is **not the verified Gale boxwork orthophoto**. Every image has a visible creator/AI disclosure. The short demo video has deliberately **not** been created or included.

## Integration

Use the raster images in the site gallery, README, or competition project description. Consider placing 01 as a cover, 02 for the core innovation, 04 for scientific grounding, 03/05 for user workflow, and 06/07 for engineering details. Verify the live site's latest UI with real screenshots separately, and never claim the conceptual sketches are actual screenshots.

The project's code and generated GLB files have separate attribution rules in `AI_USAGE.md` and `assets/AI_METADATA.json`. If a later screenshot or render contains the TRELLIS.2-generated 3D assets, embed a visible label: `AI-generated 3D assets using Microsoft TRELLIS.2` as required by the repo.
