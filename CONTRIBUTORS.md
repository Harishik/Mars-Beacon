## Team credit and GitHub statistics

This page records the team's contribution areas from the project documentation. It is not generated from commit counts: data preparation, modelling, research, backend setup and shared implementation can be integrated through another teammate's commits.

GitHub's automatic Contributors list is based on commit attribution, not accepted collaborator invitations. Both teammate accounts had write access when checked on 15 November 2026. At that check, Naomi had a commit on the separate `naomi` branch that was not in `main`; Sahaj's pipeline import was committed under Harishik's account. These historical details explain the discrepancy and do not diminish their project credit.

To receive automatic attribution for future contributions, use a GitHub-associated author email and merge genuine work into `main`. See the [contributing guide](CONTRIBUTING.md). Changes to this page cannot manually set GitHub's sidebar contributor list.
